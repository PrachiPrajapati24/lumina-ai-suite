# 🚀 Lumina AI Suite

A futuristic AI-powered MERN SaaS platform for generating captions, blogs, and study notes using OpenRouter AI with a premium modern UI.

---

## ✨ Features

* 🔥 AI Caption Generator
* 📝 AI Blog Writer
* 📚 Smart Study Notes Generator
* 📌 Pinned & Favorite Templates
* 📊 Smart History Dashboard
* 🔄 AI Regeneration System
* 📥 Export as TXT / Markdown
* 🔍 Advanced Search & Filters
* 📈 Usage Analytics
* 🔐 JWT Authentication
* ☁️ MongoDB Atlas Integration
* ⚡ OpenRouter AI Integration
* 🎨 Futuristic Glassmorphism UI
* 📱 Fully Responsive Design

---


# 📦 Installation

## Clone Repository

```bash
git clone https://github.com/yourusername/lumina-ai-suite.git
```

---

## Install Frontend

```bash
cd frontend
npm install
npm run dev
```

---

## Install Backend

```bash
cd backend
npm install
npm run dev
```
